# 綠界 stage 信用卡付款操作細節

本文件記錄綠界測試環境（stage）付款頁的實際操作方式，依 2026-11-19 實測整理。綠界頁面若改版，以畫面為準，並在回報中註明差異。

## 1. 付款頁（AIO 收銀台）

- 網址：`https://payment-stage.ecpay.com.tw/Cashier/AioCheckOut/V5`，標題「選擇支付方式|綠界科技」。
- 頁面上方顯示訂單編號（`FL` 開頭 20 碼）、商品明細與「實際付款金額」，先確認金額和訂單一致。
- 預設停在「信用卡」分頁，**不要切到其他分頁**（Apple Pay、iPASS、街口、綠界Pay）。

### 測試環境提示 modal

畫面中央可能跳出「您目前正在使用的是綠界科技的付款測試環境…」提示，出現時機可能是頁面載入或第一次按「立即付款」。按「關閉」即可，關閉後重新 snapshot 取得 ref。

### 填寫信用卡欄位

| 欄位 | 值 | 填寫方式 |
|---|---|---|
| 信用卡類型 | `VISA / MasterCard / JCB`（預設） | 不用動 |
| 卡號第 1～4 段（`#CCpart1`～`#CCpart4`） | `4311`、`9522`、`2222`、`2222` | **逐段用 `browser_type`，`slowly: true`** |
| 有效期限 MM / YY | 任意未來月份與年份，例如 `12` / `30` | `browser_fill_form` |
| 信用卡安全碼 CVV | `222`（任意三碼） | `browser_fill_form` |
| 持卡人姓名 | `WANG XIAO MING` | **只能用英文字母與空白**，不可有數字 |
| 手機號碼 | `0912345678` | `browser_fill_form` |
| 電子信箱 | 註冊用的 Email | `browser_fill_form` |
| 帳單地址 | 國家維持台灣，地址可填收件地址 | 選填 |

注意事項：

- **卡號不能用 `browser_fill_form`／一般 `fill`。** 卡號欄位靠按鍵事件驗證並自動跳到下一段，直接填值時欄位下方會出現紅字「請輸入信用卡卡號」，按「立即付款」也不會送出。用 `browser_type`（`slowly: true`）逐段輸入後，卡號旁會出現「VISA 中國信託」，代表驗證通過。
- 持卡人姓名含數字（例如 `E2E TESTER`）會出現「請輸入2個以上的英文字母或符號」。
- 其他欄位可以一次用 `browser_fill_form` 填完。

### 送出

1. 按「立即付款」（是連結，不是 button）。
2. 若出現測試環境提示 → 按「關閉」，再按一次「立即付款」。
3. 出現「您確定使用信用卡，支付此筆訂單金額(新台幣)<金額>」→ 確認金額後按「確定」。

## 2. 3D 驗證頁

- 網址：`https://cc-stage.ecpay.com.tw/form_ssl.php`，標題「交易驗證碼確認」，顯示特約商店、交易金額與遮罩卡號 `431195*******2222`。
- 步驟：
  1. 點「取得OTP服務密碼(Get the password)」。
  2. 頁面出現「(OTP密碼：1234)」與輸入框「請輸入網路刷卡OTP服務密碼」。
  3. 輸入 `1234`，點「送出(Submit)」。
- 送出後由綠界以瀏覽器 POST 導回 `http://localhost:3001/ecpay/result/<orderId>`，再 302 到 `/orders/<orderId>?payment=return`。

## 3. 疑難排解

| 狀況 | 處理 |
|---|---|
| 按「立即付款」後頁面沒變化 | snapshot 找紅字驗證訊息或 modal；snapshot 看不到時，拍一張除錯截圖到 `screenshots/` 查看 |
| 卡號下方紅字「請輸入信用卡卡號」 | 四段卡號改用 `browser_type` + `slowly: true` 重新輸入（先清空再輸入） |
| 頁面出現「測試付款請點此」按鈕 | 那是掃碼付款的模擬按鈕，不是信用卡流程，**不要點** |
| 導回後一直是「待付款」 | 銀行可能延遲回覆。依 SKILL.md §7 最多重查一次；仍未付款就照實回報 |
| 訂單頁出現「查詢太頻繁」 | 綠界查詢 API 回 403，需等 30 分鐘，停止重試並回報 |
| 綠界頁面出現錯誤代碼（例如參數錯誤） | 屬於建單參數問題，停止並回報錯誤訊息，不要自行修改 `src/services/ecpay.js` |
