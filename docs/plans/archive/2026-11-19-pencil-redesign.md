# 全站重新設計（Pencil 設計稿，夜色花房）

> 狀態：✅ 已完成（2026-11-19）。只產出設計稿，尚未切版。

## User Story

身為花漾生活的設計／開發者，我想要一份有獨特視覺識別、涵蓋所有頁面與斷點的設計稿，以便後續把前台與後台切版成 EJS + Tailwind 時有一致的依據。

## Spec

### 範圍

- 工具：Pencil MCP 繪製，搭配 `/frontend-design` skill 的流程（設計計畫 → 對照罐頭風預設清單自我審查 → 繪製 → 截圖檢查）。
- 頁面（10）：首頁、商品詳情、購物車、結帳、登入／註冊、我的訂單、訂單詳情、404、後台商品管理、後台訂單管理。
- 斷點（5）：1920（主）、1440、768、576、390。前台與後台都畫，共 50 個頁面畫板。
- 狀態稿（21，1920 與 390）：空購物車、移除確認、結帳欄位錯誤、註冊分頁、尚無訂單、付款成功導回、找不到此商品、390 選單展開、後台編輯商品、後台刪除確認、後台訂單詳情。
- 內容只用現有 API 支援的功能與 seed 資料，不畫分類、搜尋、賀卡留言等不存在的功能。

### 設計系統

| Token | Hex | 用途 |
|---|---|---|
| `plum-night` 梅夜 | `#2B1A24` | 前台底色、後台側欄 |
| `plum-raised` 深梅 | `#3B2733` | 深色底上的輸入框、頁尾 |
| `plum-line` 梅線 | `#4E3744` | 深色底上的分隔線與外框 |
| `ivory` 象牙 | `#F3EDE4` | 深色底主要文字、單據紙面 |
| `mauve` 霧藕 | `#B8A3AE` | 深色底次要文字 |
| `marigold` 金盞 | `#E8B04B` | 只用於主要動作與選取狀態 |
| `paper-ink` / `paper-ink-2` / `paper-line` | `#2B1A24` / `#6E5A64` / `#DCD2C6` | 紙面上的文字與線 |
| 狀態 | 待付款 `#E8B04B`、已付款 `#9CC59A`、付款失敗 `#E5806B` | 深色底的狀態膠囊；紙面版另有深色字（`#8A5A00`／`#2F6B35`／`#A33A23`） |

- 字體：標題與商品名用 **Cactus Classical Serif（仙人掌明體）**；內文、資料、價格、按鈕用 **Noto Sans TC**。
- 格線：1920 外距 160／1440 外距 96／768 外距 40／576 外距 24／390 外距 20；商品欄數依序為 3／3／3／2／2。
- 原則：光從花來（攝影是唯一的色彩來源）、單據是紙（交易文件放在象牙紙面）、金盞只給動作、明體說話黑體做事；照片 0 圓角、按鈕 2px，不用卡片加陰影。
- 攝影：12 張 AI 生成的暗調靜物照（Hero、登入、404、品牌故事、8 項商品），統一使用梅紫背景與單側光。

### 設計稿位置

Pencil 文件 `design/flower-life/flower-life.pen`，設計稿用到的 Pencil 產生圖片放在同層的 `images/`，移動時兩者要一起搬（.pen 只能透過 Pencil 開啟）。畫布配置：第 1 列為圖庫與設計系統（色票、字級、元件、原則），其後每頁一列，依序為 `1920 | 1440 | 768 | 576 | 390 | 狀態稿`。

### 對既有模組的影響

無。本次只產出設計稿，沒有修改程式碼。發現一個小問題：seed 商品最低售價 NT$580，所以任何非空購物車都會超過 NT$500 免運門檻，`cart.ejs` 的「再買 NT$ X 即可免運」分支在 seed 資料下不會出現。
